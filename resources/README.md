# Resources

Everything the DCR tracker backend reads at runtime.

**Project e-mails:** save each project's e-mails in a folder named after the project number, directly in
this folder (e.g. `resources/20251234/`). In the app, **From project** reads that folder and fills a draft.

| Path | What it is |
|---|---|
| `template_SOP.xlsx` | The DCR tracker workbook (SOP 5-A1 "DCR Tracker and CAPA Overview"). Sheet **Main Sheet** is imported on first start; **Formulas** holds the drop-down lists; **Instructions and definitions** defines each field. |
| `SOP 5 - Attachment 2 - CAPA Report V4 1.docx` | CAPA report template (SOP 5, attachment 2). Not used by the code yet. |
| `sample_emails/*.eml` | 20 **synthetic** test e-mails modelled on real DCR threads (generated by `scripts/make_sample_emails.py`). Not used by the project lookup. |
| `20241189/`, `20250342/`, `20251234/`, `20251792/`, `20252275/`, `20252675/`, `20261234/` | **Real** Outlook e-mails (.msg), one folder per AMEX project; these are the projects the wizard offers. |
| `SHOWCASE/` | Demo copies of the 20241189 and 20251792 threads, plus 20260684. The wizard does not look here. `20251792/…Miglustat (10).msg` is corrupt and is skipped. |
| `TEST_NEW_ENTRIES/` | **Real** e-mails for incidents that are not yet in the tracker. The wizard does not look here. |
| `SOP 5 - Deviations Complaints Recalls and CAPA Management V12_Final_Signed.pdf`, `SOP 5 - Attachment 1 - … template V4.pdf` | The SOP 5 document and the tracker template as PDF. Reference only. |
| `SOP 5 - Attachment 1 - DCR Tracker and CAPA overview - V2 (October 2024).xlsx` | The original tracker file from the e-mail folder. Same 300 cases as `template_SOP.xlsx`; not used by the app. |
| `master_data/parties.json` | E-mail domain → partner lookup (currently the test e-mail domains). Project → customer/supplier lookups are learned from the tracker itself. |
| `output/DCR_Tracker.xlsx` | Working copy of the tracker that the app reads and writes (git-ignored). |
| `data/dcr_state.json` | Drafts from the wizard and the e-mails linked to each DCR (git-ignored). `POST /api/admin/reset` clears it and the working tracker. |
